## Why

The first AgentRetro decomposition removed the largest orchestration hotspots and established a scoped complexity gate, but six AgentRetro functions remain above the agreed McCabe ceiling of 15. Completing the boundary now keeps session ingestion, sensitive-header redaction, Codex guidance, brief composition, merge planning, and review presentation from becoming the next concentrated change risks.

## What Changes

- Extend the existing AgentRetro complexity manifest and architecture coverage to the six remaining hotspot modules.
- Decompose brief composition and semantic-merge planning into focused internal steps while preserving budgets, deadlines, deterministic ordering, plan identity, and public service signatures.
- Decompose Codex session parsing and Codex guidance execution while preserving bounded reads, source identity, path containment, backup-first writes, rollback states, and monkeypatch seams.
- Decompose sensitive-header scanning without weakening fail-closed credential redaction, header-boundary handling, idempotency, or linear-time behavior.
- Decompose review command routing/rendering while preserving command arguments, JSON/human envelopes, exit codes, retry behavior, and projection recovery fields.
- Preserve all runtime dependencies, persisted formats, public imports, CLI contracts, security boundaries, and application behavior; this is a second behavior-preserving maintainability phase.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `agentretro-maintainability`: Extend the measurable complexity and compatibility boundary to every remaining AgentRetro C901 hotspot, including bounded session parsing and credential-redaction invariants.

## Impact

- Affected code: `application/brief.py`, `application/merge_planner.py`, `infrastructure/codex_guidance.py`, `infrastructure/codex_sessions.py`, `infrastructure/redaction.py`, and `presentation/review_commands.py`, plus focused private collaborators where responsibility ownership is clearer.
- Affected tests and CI: briefing/value-loop, semantic merge, Codex session hardening, Codex integration, capture/redaction, review/CLI, architecture manifest, and the existing scoped C901 job.
- Public API and data: no intended change to constructors, commands, envelopes, event/session identity, plan formats, SQLite/vault data, credentials, or recovery semantics.
- Dependencies and operations: no new runtime dependency, migration, background process, credential flow, or external write surface.
